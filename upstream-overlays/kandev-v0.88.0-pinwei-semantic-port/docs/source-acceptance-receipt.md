## Patch series

22-commit port (`cab9eaf19d997bb4c8020dd263ddc60d5b035b64..c70fd4fb7d77d3f679f2639ab992c6868240e773`).
Each patch is a full-binary, full-index mailbox patch and is validated
independently against the manifest's `patch_order_subjects`. Filenames use
git's standard subject-slug format; the verifier does not depend on filenames,
only on the patch order and `Subject:` lines.
