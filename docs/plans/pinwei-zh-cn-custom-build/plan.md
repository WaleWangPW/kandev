# 品蔚简体中文定制构建计划

## 目标与边界

在 Kandev `v0.83.0` 的隔离分支中提供简体中文优先的界面，同时保留英文切换。
本定制不改后端任务状态枚举、数据库值、工作区数据或任务关系；`Backlog`、`In Progress`、`Review`、`Done` 等仅在展示层翻译。

当前生产 Kandev 和 `~/.kandev` 数据不在此分支的构建、测试或迁移范围内。

## 已完成：高频任务流前四批

- 新增轻量本地 UI locale 层，默认 `zh-CN`，可在侧边栏底部切回 English。
- 覆盖主页、收件箱、新建任务、快速对话、设置入口、看板/协作中心和常用筛选词。
- 覆盖任务及会话状态：待办、进行中、审核、已完成、已阻塞、正在调度、运行中等。
- 看板列标题和 WIP 超限提示使用展示层翻译。
- 覆盖会话恢复、环境准备状态、空会话/加载提示、任务工作台命令和移动端的核心面板导航。
- 覆盖 Office 的新建任务、项目/执行人/验收人选择、分组排序，以及设置总入口。
- 语言选择仅保存在浏览器 `localStorage`，不写入服务器或任务数据；切换后会同路由刷新一次，确保旧的纯展示辅助函数也立即采用新语言。

## 后续批次

1. **任务流与会话**：剩余任务详情、操作菜单、终端、错误提示与快捷键。
2. **管理与集成**：设置页细项、Agent/执行器、模型、权限、GitHub/企微等集成、统计和更新说明。
3. **全界面收尾**：其余 Office、移动端、ARIA 标签、日期/数量格式、E2E 覆盖与英语回退检查。

每批都先由脚本生成英语文案清单，再将稳定 UI 文案纳入 locale 字典；动态任务标题、用户输入、日志和业务正文保持原样，不做机器翻译或改写。

## 验收门

- 前端格式化、类型检查、定向单元测试和生产 Vite 构建通过。
- 桌面启动页与完整 macOS `.app` 已用隔离 Rust/Tauri 工具链构建；候选包仅在临时目录作 ad-hoc 签名。
- 使用全新的临时本地数据目录做健康冒烟已通过；中文默认、英文切换、四个看板状态、任务创建和会话展示仍需在候选界面做手工验证。
- 升级切换前另行导出当前应用版本、数据库备份和回滚包；未完成这些门前不替换正在使用的 Kandev。

## 上游贡献策略

先在本分支完成可维护的 locale 基础层和测试，再用独立 GitHub fork 提交一个只含通用 i18n 架构/英语默认行为的 PR。品蔚默认中文、术语表和本地部署说明保留在定制分支，避免把组织偏好强加给上游。
